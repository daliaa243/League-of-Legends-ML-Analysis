# League-of-Legends-ML-Analysis
Built ML models (Logistic Regression, Decision Tree) to predict match outcomes (Accuracy ~0.88, AUC ~0.95). Performed preprocessing, feature engineering (gold/XP diff), and applied K-Means and PCA for pattern analysis and feature importance.
this project as trying to answer a simple but powerful question: can we predict who will win a professional video game match early on, just by looking at what happens in the first few minutes? We used real match data from League of Legends (over 50,000 games) and focused on what happens around the 15-minute mark. By carefully cleaning the data and extracting meaningful indicators—like gold advantage, experience difference, kills, and assists—we trained intelligent models to recognize patterns that humans might miss. The result? We were able to predict match outcomes with very high accuracy, showing that early performance strongly determines who wins.

What makes this project strong is not just prediction, but understanding. We didn’t treat the models like black boxes—we used interpretable techniques (like Logistic Regression and Decision Trees) to actually explain why a team is likely to win. For example, we found that even small early advantages in resources can dramatically increase the chance of victory. On top of that, we used clustering techniques to uncover hidden match types—like one-sided games versus close matches—giving a deeper, more strategic view of how games unfold.

In simple terms, this project turns raw game data into actionable insights. It shows how machine learning can go beyond numbers to support decision-making—whether for players, coaches, or analysts. And more importantly, it demonstrates the ability to take a complex, messy real-world dataset, transform it into something meaningful, and extract clear, high-impact conclusions from it.
